# Third-party notices

## Twemoji Country Flags (flag emoji font)

The Windows system fonts have no flag emoji, so extension and repository names that contain a
flag (for example 🇮🇶) would show two letters. The app bundles the **Twemoji Country Flags** font,
through the npm package `country-flag-emoji-polyfill` (MIT), and uses it for the flag characters only.
